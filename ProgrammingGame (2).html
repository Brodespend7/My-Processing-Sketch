Python Cheat Sheet

1. Variables

Store values in named containers.

hero = "Knight" hp = 100

2. Strings

Text wrapped in quotes.

spell = 'Fireball' element = "Ice"

3. Arithmetic

Basic math operations (+, -, *, /).

damage = 10 * 2 total_hp = 50 + 25

4. Comparisons

Evaluate True or False (==, >, <, >=, <=).

is_ready = True has_key = (keys > 0)

5. If / Else Conditions

Branch code based on rules.

if hp > 0: status = "Alive" else: status = "Defeated"

6. Lists

Ordered collections of items.

items = ["potion", "shield"] first_item = items[0] # Index 0

7. Dictionaries

Key-Value storage mappings.

stats = {"hp": 100, "mp": 50} current_hp = stats["hp"]

8. For Loops

Repeat actions multiple times.

for i in range(3): print("Attack!")

9. String Methods

Transform string text easily.

name = "hero".upper() # "HERO" clean = " text ".strip()

10. Functions

Reusable code blocks defined with def.

def cast_spell(power): return power * 2
